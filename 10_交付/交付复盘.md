## 3. 上线方案

### 3.1 部署步骤（本机单机，真实执行过的顺序）

1. **准备环境变量**：`copy .env.example .env`，填写 MySQL 密码、`JWT_SECRET`（≥32 字节）、`INTERNAL_API_TOKEN`、`CREDENTIAL_AES_KEY`、`DASHSCOPE_API_KEY`。
2. **启动中间件**：`cd 05_代码; docker compose --env-file .env up -d rabbitmq mosquitto`；`docker start swa-mysql`（或单独 `docker run` 映射 3310）。
3. **初始化数据库**：`docker exec -i swa-mysql mysql -uroot -p<密码> --default-character-set=utf8mb4 swa < db/init.sql`；回读中文种子断言（失败日志 #30 的教训）。
4. **构建并启动后端**：`cd backend; mvn -DskipTests clean package`；**先停旧 java 进程再 package**（Windows jar 锁，失败日志 #28）；`java -jar target/java-backend-1.0.0.jar`（环境变量从 `.env` 注入）。
5. **启动 Agent**：`cd agent-python; python -m venv .venv; .venv\Scripts\pip install -r requirements.txt`；`.venv\Scripts\python.exe -u -m uvicorn app.main:app --env-file .env --host 0.0.0.0 --port 8085`。
6. **启动前端**：`cd frontend; npm install; npm run dev`（开发）或 `npm run build` + 静态托管（生产）。
7. **健康检查**：三个探活全 200；用 `admin_acme/Swa@123456` 登录，确认 5 个菜单可见。
8. **端到端自检**：创建流程 → 保存 → 执行 → SSE 看到节点状态 → 回放 → 发一条 MQTT 消息触发新实例。
