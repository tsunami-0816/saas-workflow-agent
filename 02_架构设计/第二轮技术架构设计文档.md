## P1修复补充

### 1. HTTP节点超时配置
- RestTemplate配置：连接超时5s，读取超时10s
- 非2xx状态码 → 节点标记FAILED，自动重试3次（间隔2s）
- 重试3次仍失败 → 整个流程标记FAILED，SSE推送失败原因

### 2. Redis并发信号量Lua脚本
```lua
-- 尝试获取并发名额
local current = redis.call('GET', KEYS[1]) or '0'
if tonumber(current) < tonumber(ARGV[1]) then
    redis.call('INCR', KEYS[1])
    return 1
else
    return 0
end
```
- key: `concurrency:{tenantId}`
- 流程结束时DECR释放
- 超限 → 流程排队，30s后重试

### 3. MQTT连接器链路
```
EMQX接收设备消息（topic: device/{deviceId}/data）
  → MQTT订阅监听器收到消息
  → 查找哪些流程订阅了该topic
  → 触发对应流程实例执行
  → 消息payload作为流程输入参数
```
- 先Mock实现：提供一个POST /api/mqtt/mock接口模拟设备消息触发
